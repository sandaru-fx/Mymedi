# 🏥 MyMedi - Medicine Price Transparency Platform

MyMedi is a modern web application designed to empower citizens by providing transparency in medicine pricing. In a time where medicine prices fluctuate, this platform allows users to check prices and report any discrepancies or inquiries directly to the relevant authorities.

🚀 **Live Demo:** [https://mymedi-frontend.onrender.com](https://mymedi-frontend.onrender.com)

---

## ✨ Features

- **🔍 Smart Search:** Easily find medicines and their regulated prices.
- **📝 Inquiry System:** Users can submit inquiries or complaints about high-priced medicines.
- **📱 Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
- **⚡ Fast Performance:** Built using Vite for an ultra-fast development and user experience.

## 🛠️ Tech Stack

- **Frontend:** [React.js](https://reactjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Deployment:** [Render](https://render.com/)

## 🚀 Future Improvements (Roadmap)

- [ ] **Email Integration:** Connecting the inquiry form with EmailJS for real-time notifications.
- [ ] **Admin Dashboard:** To manage medicine data and review user complaints.
- [ ] **Price Comparison:** Automating price checks against official NMRA (National Medicines Regulatory Authority) gazette data.
- [ ] **Backend Integration:** Moving from static mock data to a full Supabase/Node.js backend.

## ⚙️ Local Setup

1. Clone the repository:
   ```bash
   git clone [https://github.com/sandaru-fx/Mymedi.git](https://github.com/sandaru-fx/Mymedi.git)
   ```

2. Navigate to the project folder:

```Bash

cd Mymedi
```

3. Install dependencies:

```Bash

npm install
```

4. Start the development server:

```Bash

npm run dev
```
