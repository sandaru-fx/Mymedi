# MediGuide AI - Technologies & Tools

A comprehensive overview of the technologies, tools, and libraries used in the MediGuide AI project.

## 🚀 Core Stack

### Frontend
- **React 19**: Modern UI library for building the user interface.
- **Vite**: Ultra-fast build tool and development server.
- **TypeScript**: Typed JavaScript for better developer experience and reliability.

### Backend
- **Node.js**: JavaScript runtime environment.
- **Express**: Fast, unopinionated, minimalist web framework for building APIs.
- **MongoDB**: NoSQL database for flexible data storage.
- **Mongoose**: ODM (Object Data Modeling) library for MongoDB and Node.js.

---

## 🎨 UI/UX & Styling
- **Tailwind CSS**: Utility-first CSS framework for rapid styling (loaded via CDN).
- **Three.js**: 3D library used for the interactive `MedicalScene` component.
- **Lucide React**: Modern icon library for high-quality SVG icons.
- **Google Fonts**:
  - `Plus Jakarta Sans`: Clean, modern font for the primary interface.
  - `Noto Sans Sinhala`: Optimized font for Sinhala language support.

---

## 🧠 Intelligence & APIs
- **Google Gemini AI**: Powering the medical intelligence engine (`gemini-1.5-flash`).
  - Medicine Information Retrieval
  - Symptom Analysis
  - First-aid & Emergency Instructions

---

## 🛠️ Developer Tools
- **Nodemon**: Automatically restarts the server during development.
- **Dotenv**: Manages environment variables for secrets and configurations.
- **CORS**: Middleware to enable Cross-Origin Resource Sharing.
